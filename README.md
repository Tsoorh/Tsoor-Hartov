## 🚀 איך להפעיל את הפרויקט

### 1. תצוגה מקדימה מיידית (ללא צורך בהתקנת חבילות)
ניתן פשוט לפתוח את הקובץ הבא בדפדפן (Chrome / Edge / Firefox):
`c:\Users\tsoor.hartov\TSOOR\client\preview.html`
הוא מכיל את האפליקציה המלאה עם React, Tailwind והחלפת שפות עברית/אנגלית.

### 2. הפעלת צד שרת (Node.js Express)
```bash
cd server
npm install
npm run dev   # או: node server.js
```
השרת יעלה על כתובת: `http://localhost:5000`
* בדיקת תקינות: `http://localhost:5000/api/health`
* צפייה בלידים: `http://localhost:5000/api/leads`

### 3. הפעלת צד לקוח (React Vite)
```bash
cd client
npm install
npm run dev
```
האתר ייפתח בכתובת: `http://localhost:3000`
ברירת המחדל היא עברית, עם כפתור החלפה לאנגלית בראש העמוד וב-Footer.
